# Course Website

Static GitHub Pages skeleton for **Selected Topics on Deep Learning over Structured Data**.

## Edit Content

- `index.html` contains the page structure and placeholder text.
- `styles.css` contains the visual design and responsive layout.

## Publish On GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository settings, open **Pages**.
3. Set the source to the branch containing these files and the root folder.
4. GitHub Pages will serve `index.html` automatically.
